# Image showcase samples

The `demo_samples` folder contains three upload images for each of the seven civic categories:

- `water`
- `road_transport`
- `waste`
- `electricity`
- `healthcare`
- `food`
- `drainage`

A few categories have two augmented views derived from the same generated source scene. The `sample_manifest.csv` file records each sample's origin and variant type.

These images are intended for manual testing of the showcase upload flow. They are not a representative training corpus for real citizen photos. The image model always requests staff verification.
