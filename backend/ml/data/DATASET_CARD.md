# Synthetic civic complaint showcase dataset

- File: `showcase_complaints.csv`
- Rows: 839
- Categories: water, road_transport, waste, electricity, healthcare, food, drainage
- Language styles: Bangla, Banglish, English
- Severity labels: low, medium, high
- Generation: deterministic templates with varied locations, time phrases, and severity prefixes.
- Split: grouped by scenario template to reduce direct template leakage.

This dataset was generated for a project showcase. It is not collected from citizens, is not representative of any city, and must not be used as evidence of real-world model performance.
